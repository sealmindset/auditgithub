# Phase 18 Plan 01: Navigation Redesign

## Objective

Improve navigation with active state highlighting, breadcrumbs component, and quick search functionality in the header.

## Execution Context

**Phase dependencies:**
- Phase 11: Dashboard Foundation
- Existing app-sidebar.tsx and layout.tsx

**Key files to create/modify:**
- `src/web-ui/components/app-sidebar.tsx` - Add active state detection
- `src/web-ui/components/Breadcrumbs.tsx` - New breadcrumb component
- `src/web-ui/components/QuickSearch.tsx` - New quick search component
- `src/web-ui/app/layout.tsx` - Integrate breadcrumbs and search

**Existing patterns to follow:**
- Sidebar component structure from shadcn/ui
- Command component for search (cmdk)

## Context

**Current navigation:**
- Sidebar with groups: Platform, Settings
- Items: Dashboard, Findings, Repositories, Scheduler, Attack Surface, Zero Day Analysis (expandable)
- No active state highlighting
- No breadcrumbs
- No quick search

**Improvements:**
1. Active state based on current pathname
2. Breadcrumbs showing navigation hierarchy
3. Command palette (Cmd+K) for quick navigation

## Tasks

### Task 1: Add Active State to Sidebar

Enhance app-sidebar.tsx:
- Use usePathname() hook to detect current route
- Apply isActive prop to SidebarMenuButton
- Handle nested routes (e.g., /findings/[id] highlights Findings)

### Task 2: Create Breadcrumbs Component

Create component that:
- Parses current pathname into segments
- Maps segments to readable names
- Provides navigation links for each level
- Shows on all pages except dashboard

### Task 3: Create QuickSearch Component

Create command palette:
- Triggered by Cmd+K / Ctrl+K
- Lists all navigation items
- Filters as user types
- Navigates on selection

### Task 4: Integrate into Layout

- Add Breadcrumbs to header bar
- Add QuickSearch to layout
- Add keyboard shortcut hint in header

## Verification

- Active nav item highlighted when on that page
- Breadcrumbs show correct hierarchy
- Cmd+K opens search dialog
- Search filters and navigates correctly

## Success Criteria

- [ ] Sidebar shows active state for current route
- [ ] Breadcrumbs component created and integrated
- [ ] QuickSearch command palette created
- [ ] Keyboard shortcut (Cmd+K) works
- [ ] All navigation items searchable
