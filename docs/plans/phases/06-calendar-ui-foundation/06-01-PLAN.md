# Phase 6.1: Calendar UI Foundation

## Objective

Create a calendar-based schedule visualization using react-big-calendar with monthly/weekly views, schedule event rendering, and time window badges. The calendar will display scan schedules from the Phase 2 API endpoints.

## Library Decision

**Selected: react-big-calendar** over FullCalendar because:
- MIT license (FullCalendar premium features require paid license)
- Lightweight (~50KB gzipped vs ~150KB for FullCalendar)
- Native React component (not a wrapper)
- Simpler API for basic calendar views
- Better compatibility with date-fns (already considering for date manipulation)

## Context

**API Endpoints (from Phase 2):**
- GET /schedules - List all schedules with ScheduleListResponse
- Each schedule has: id, repository_name, frequency, day_of_week, time_window, next_scheduled_at, is_locked, schedule_type

**ScheduleResponse fields for calendar:**
```typescript
interface Schedule {
  id: string;
  repository_id: string;
  repository_name: string;
  schedule_type: "ai" | "manual";
  frequency: "daily" | "weekly" | "bi-weekly" | "monthly";
  day_of_week: number | null;  // 0=Monday, 6=Sunday
  time_window: "morning" | "afternoon" | "evening" | "night";
  next_scheduled_at: string | null;
  is_locked: boolean;
  ai_confidence: number | null;
}
```

**Time window hours (from STATE.md decisions):**
- morning: 8:00
- afternoon: 14:00
- evening: 20:00
- night: 2:00

**UI Patterns:**
- Pages use "use client" directive
- Data fetching via useEffect with API_BASE = "http://localhost:8000"
- Badges from @/components/ui/badge for status indicators
- Lucide icons for visual elements
