# Phase 15 Plan 01: Finding Trends Widget

## Objective

Create a dashboard widget showing finding trends over time with a stacked area chart visualizing severity distribution (critical, high, medium, low) across a 30-day period.

## Execution Context

**Phase dependencies:**
- Phase 11: Dashboard Foundation (Widget component, useWidgetData hook)

**Key files to modify:**
- `src/api/routers/analytics.py` - New finding-trends endpoint
- `src/web-ui/components/dashboard/FindingTrendsWidget.tsx` - New widget
- `src/web-ui/components/dashboard/index.ts` - Export
- `src/web-ui/app/page.tsx` - Add to dashboard

**Existing patterns to follow:**
- SecurityOverviewWidget for widget structure and recharts usage
- Widget wrapper with useWidgetData for loading/error states

## Context

**Charting library:**
- recharts (already installed, used by SecurityOverviewWidget)

**API design:**
- Returns timeline data points with severity counts per day
- Includes current totals for legend display

## Tasks

### Task 1: Create Finding Trends API Endpoint

Add `/analytics/finding-trends` endpoint that:
- Accepts `days` parameter (default 30)
- Returns daily counts by severity level
- Includes current total open findings
- Supports organization filtering

### Task 2: Create FindingTrendsWidget Component

Create component with:
- Stacked area chart (recharts AreaChart)
- Color-coded severity areas (red/orange/yellow/green)
- Trend indicator comparing first half vs second half
- Custom legend with current counts
- 2-minute auto-refresh

### Task 3: Export and Add to Dashboard

Export from index.ts and add to dashboard page as full-width section.

## Verification

- Widget renders with stacked area chart
- Severity colors match design system
- Trend indicator shows improvement/decline
- Auto-refresh works at 2-minute interval
