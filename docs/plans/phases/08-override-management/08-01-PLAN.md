**Files:**
- `src/web-ui/components/SchedulerCalendar.tsx`
- `src/web-ui/app/scheduler/page.tsx`

**Action:**
1. In SchedulerCalendar:
   - Import and render ScheduleOverrideDialog
   - Pass selectedSchedule and dialog open state
   - Pass lock/unlock handlers from props

2. In page.tsx:
   - Add handleLockSchedule function: POST /schedules/{repo_id}/lock
   - Add handleUnlockSchedule function: DELETE /schedules/{repo_id}/lock
   - Implement optimistic UI: immediately update is_locked in local state
   - Rollback on error, show toast
   - Refetch schedules after successful lock/unlock

3. API calls:
   ```typescript
   // Lock
   const lockSchedule = async (repoId: string, reason: string) => {
     const res = await fetch(`${API_BASE}/schedules/${repoId}/lock`, {
       method: 'POST',
       headers: { 'Content-Type': 'application/json' },
       body: JSON.stringify({ reason })
     });
     if (!res.ok) throw new Error('Failed to lock schedule');
     return res.json();
   };

   // Unlock
   const unlockSchedule = async (repoId: string) => {
     const res = await fetch(`${API_BASE}/schedules/${repoId}/lock`, {
       method: 'DELETE'
     });
     if (!res.ok) throw new Error('Failed to unlock schedule');
     return res.json();
   };

   // History (in dialog component)
   const fetchHistory = async (repoId: string) => {
     const res = await fetch(`${API_BASE}/schedules/${repoId}/history`);
     if (!res.ok) throw new Error('Failed to fetch history');
     return res.json();
   };
   ```

4. Handle dialog close: clear selectedSchedule state

**Verification:**

- Lock button → API call → schedule shows lock indicator
- Unlock button → API call → lock indicator removed
- History tab → shows override entries
- Toast notifications on success/error
