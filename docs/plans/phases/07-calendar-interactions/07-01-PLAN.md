**API call:**
```typescript
const updateSchedule = async (repoId: string, update: ScheduleUpdate) => {
  const res = await fetch(`${API_BASE}/schedules/${repoId}`, {
    method: 'PUT',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(update)
  });
  if (!res.ok) throw new Error('Failed to update schedule');
  return res.json();
};
```

### Task 4: Add optimistic UI and error rollback

Implement optimistic updates with rollback on API failure.

**Files:**
- `src/web-ui/components/SchedulerCalendar.tsx`
- `src/web-ui/app/scheduler/page.tsx`

**Action:**
1. On dialog confirm:
   - Store previous schedule state (for rollback)
   - Immediately update local state (optimistic)
   - Close dialog
   - Make API call

2. On API success:
   - No additional action needed (state already updated)
   - Show success toast

3. On API failure:
   - Rollback to previous state
   - Show error toast with message
   - Re-open dialog with error state (optional)

4. Add loading state during API call:
   - Disable Confirm button while submitting
   - Show spinner or "Saving..." text

**Verification:**
- UI updates immediately on confirm
- On API error: UI reverts to original state
- Toast shows success/error message
- Loading state prevents double-submit
