# Phase 14 Plan 01: Repository Health Widget

## Objective

Create a dashboard widget showing repository health with risk scores, finding counts, and status indicators. Shows top 8 repositories sorted by risk score.

## Execution Context

**Phase dependencies:**
- Phase 11: Dashboard Foundation (Widget component, useWidgetData hook)

**Key files to modify:**
- `src/web-ui/components/dashboard/RepositoryHealthWidget.tsx` - New widget
- `src/web-ui/components/dashboard/index.ts` - Export
- `src/web-ui/app/page.tsx` - Add to dashboard

**Existing patterns to follow:**
- SecurityOverviewWidget for widget structure
- Widget wrapper with useWidgetData for loading/error states

## Context

**Available API endpoint:**
- `GET /analytics/risk-heatmap?limit=8` - Returns repositories with risk scores

**RepoRiskItem data structure:**
```typescript
{
  id: string
  name: string
  riskScore: number  // 0-100
  riskLevel: "critical" | "high" | "medium" | "low"
  criticalFindings: number
  highFindings: number
  secretsCount: number
  isArchived: boolean
  isAbandoned: boolean
}
```

## Tasks

### Task 1: Create RepositoryHealthWidget Component

Create component with:
- Risk score progress bars with color coding
- Critical/high/secrets badges
- Archived and abandoned indicators
- Summary stats in subtitle
- 60-second auto-refresh

### Task 2: Export and Add to Dashboard

Export from index.ts and add to dashboard page as full-width section.

## Verification

- Risk scores shown with color-coded progress bars
- Badges display for critical/high/secrets findings
