# Milestone v1.0: Rescan Scheduler

**Status:** SHIPPED 2026-01-17
**Phases:** 1-10
**Total Plans:** 10

## Overview

Build an AI-powered intelligent scanning scheduler that automatically determines optimal rescan timing based on commit patterns, finding history, file types, contributor activity, and risk scores. The journey progresses from database foundation through AI engine to a beautiful calendar-based UI with drag-and-drop rescheduling and manual override capabilities.

## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**
- Calendar view over table interface (visual scheduling)
- Manual lock prevents AI modification (user control)
- react-big-calendar over FullCalendar (MIT license, lighter)
- date-fns over moment (tree-shakeable, ESM)
- One schedule per repo via unique constraint
- 90-day lookback for commit analysis
- Heuristic fallback when AI unavailable
- Lazy-load history/scanners on tab activation
- Empty scanners array = use all scanners

- Fixed TypeScript errors in existing components (Phase 8)
