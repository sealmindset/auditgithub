# Phase 16 Plan 01: Quick Actions Panel

## Objective

Create a dashboard widget providing quick access to common actions: trigger scans, view reports, jump to scheduler, and access findings.

## Execution Context

**Phase dependencies:**
- Phase 11: Dashboard Foundation (Widget component)

**Key files to modify:**
- `src/web-ui/components/dashboard/QuickActionsWidget.tsx` - New widget
- `src/web-ui/components/dashboard/index.ts` - Export
- `src/web-ui/app/page.tsx` - Add to dashboard

**Existing patterns to follow:**
- BackgroundJobsWidget for action buttons
- Widget wrapper for consistent styling

## Context

**Quick actions to include:**
1. **Trigger Full Scan** - Link to scheduler or trigger endpoint
2. **View All Findings** - Link to /findings
3. **Open Scheduler** - Link to /scheduler
4. **View Reports** - Link to /reports (or findings export)
5. **Manage Repositories** - Link to /projects

**Design approach:**
- Grid of action cards with icons
- Each card is a link or button
- Minimal widget - no data fetching needed

## Tasks

### Task 1: Create QuickActionsWidget Component

Create component with:
- Grid layout of action cards (2x3 or similar)
- Icon + label for each action
- Links to appropriate pages
- Consistent styling with other widgets

### Task 2: Export and Add to Dashboard

Export from index.ts and add to dashboard in appropriate location.

## Verification

- All action links navigate correctly
- Icons and labels are clear
- Responsive grid layout works on different sizes
