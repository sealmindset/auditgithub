# Phase 19 Plan 01: Repository Schedule Table

## Objective

Create a table view on the Scheduler page showing ALL repositories with their schedule status, last commit date, next scheduled scan, and quick actions. This replaces the empty state when no schedules exist.

## Execution Context

**Phase dependencies:**
- v1.0: Existing schedule API and models
- Existing projects API returns repos with `pushed_at` and `last_scanned_at`

**Key files to create/modify:**
- `src/api/routers/schedules.py` - New endpoint for repos with schedule info
- `src/web-ui/components/RepositoryScheduleTable.tsx` - New table component
- `src/web-ui/app/scheduler/page.tsx` - Integrate table view

**Existing patterns to follow:**
- DataTable pattern from findings page (if exists)
- Widget/Card patterns from dashboard

## Context

**Current state:**
- Scheduler page shows calendar with scheduled repos
- Empty state shown when no schedules exist
- No way to see repos WITHOUT schedules
- No way to create schedules from UI

**Desired state:**
- Show table of ALL repos below calendar
- Columns: Repo Name, Last Commit, Last Scan, Schedule Status, Next Scan, Actions
- Actions: Create Schedule (if none), Edit, Trigger Scan
- Sortable by any column
- Filter by schedule status (scheduled/unscheduled)

## Tasks

### Task 1: Create API Endpoint for Repos with Schedule Info

Add `/schedules/repositories` endpoint that:
- Returns all repos with LEFT JOIN to schedules
- Includes: repo name, pushed_at, last_scanned_at, schedule info (if exists)
- Supports org filtering

### Task 2: Create RepositoryScheduleTable Component

Create table component with:
- Columns: Name, Last Commit, Last Scan, Schedule, Next Scan, Actions
- Schedule status badge (Scheduled/Unscheduled)
- Frequency/time window display for scheduled repos
- Action buttons (Edit, Trigger, Create Schedule)
- Sortable columns
- Filter tabs (All, Scheduled, Unscheduled)

### Task 3: Integrate into Scheduler Page

- Add table below calendar
- Add toggle to show/hide calendar view
- Keep stats badges in header

## Verification

- Table shows all repos including those without schedules
- Correct last commit and scan dates displayed
- Schedule status accurately shown
- Action buttons visible and functional (UI only, handlers in Phase 20-21)

## Success Criteria

- [ ] `/schedules/repositories` endpoint created
- [ ] RepositoryScheduleTable component created
- [ ] Shows all repos with schedule status
- [ ] Displays last commit (pushed_at) and last scan dates
- [ ] Schedule frequency/time shown for scheduled repos
- [ ] Filter tabs work (All/Scheduled/Unscheduled)
- [ ] Integrated into scheduler page
