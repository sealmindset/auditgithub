**tests/unit/test_redaction.py** - src/api/utils/redaction.py:

Test cases:
1. **redact_string()** - Pattern-based string scrubbing
   - "password=secret123" → "password=***REDACTED***"
   - "Bearer eyJhbGc..." (JWT) → "Bearer ***JWT***"
   - "postgres://user:pass@host" → "postgres://user:***REDACTED***@host"
   - "user@example.com" → "***EMAIL***"
   - No sensitive data → unchanged
   - Empty string → empty string

2. **redact_dict()** - Recursive dictionary redaction
   - {"password": "secret"} → {"password": "***REDACTED***"}
   - {"token": "abc123"} → {"token": "***REDACTED***"}
   - Nested dicts → redacts recursively
   - Lists of dicts → redacts each item
   - Non-sensitive keys → unchanged

3. **Edge cases:**
   - None values → handled gracefully
   - Non-string values in dict → unchanged
   - Circular references → doesn't crash (if applicable)

Use the 7 regex patterns from Phase 6 Plan 03.
