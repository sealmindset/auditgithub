<task type="auto">
  <name>Task 2: Create GitHub Actions CI workflow</name>
  <files>.github/workflows/test.yml</files>
  <action>Create GitHub Actions workflow for automated testing on PR:

**Create .github/workflows/test.yml:**
```yaml
name: Tests

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

jobs:
  test:
    runs-on: ubuntu-latest
    timeout-minutes: 15

    services:
      postgres:
        image: postgres:15
        env:
          POSTGRES_USER: auditgh
          POSTGRES_PASSWORD: auditgh_test
          POSTGRES_DB: auditgh_test
        ports:
          - 5432:5432
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

      redis:
        image: redis:7-alpine
        ports:
          - 6379:6379
        options: >-
          --health-cmd "redis-cli ping"
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Set up Python 3.11
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'
          cache: 'pip'

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt

      - name: Run tests with coverage
        env:
          DATABASE_URL: postgresql://auditgh:auditgh_test@localhost:5432/auditgh_test
          REDIS_URL: redis://localhost:6379/0
          JWT_SECRET: test-secret-key-do-not-use-in-production
          CRIBL_ENABLED: false
        run: |
          pytest --cov=src --cov-report=xml --cov-report=term-missing

      - name: Upload coverage to Codecov
        uses: codecov/codecov-action@v4
        with:
          file: ./coverage.xml
          flags: unittests
          name: codecov-umbrella
          fail_ci_if_error: false

      - name: Check minimum coverage
        run: |
          COVERAGE=$(python -c "import xml.etree.ElementTree as ET; root = ET.parse('coverage.xml').getroot(); print(root.attrib['line-rate'])")
          COVERAGE_PCT=$(python -c "print(int(float($COVERAGE) * 100))")
          echo "Current coverage: $COVERAGE_PCT%"
          if [ $COVERAGE_PCT -lt 70 ]; then
            echo "ERROR: Coverage $COVERAGE_PCT% is below minimum 70%"
            exit 1
          fi
          echo "Coverage check passed: $COVERAGE_PCT% >= 70%"

  lint:
    runs-on: ubuntu-latest
    timeout-minutes: 5

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Set up Python 3.11
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install linting tools
        run: |
          python -m pip install --upgrade pip
          pip install flake8 black isort

      - name: Run Black (code formatting)
        run: black --check src/ tests/

      - name: Run isort (import sorting)
        run: isort --check-only src/ tests/

      - name: Run Flake8 (linting)
        run: flake8 src/ tests/ --max-line-length=120 --ignore=E203,W503
```

**Key features:**
- Runs on every PR and push to main/develop
- Uses PostgreSQL and Redis services for integration tests
- Caches pip dependencies for faster runs
- Uploads coverage to Codecov (optional, requires token)
- Enforces minimum 70% coverage (fails CI if below)
- Separate lint job (Black, isort, Flake8)
- 15-minute timeout to prevent hanging tests

**Environment variables:**
- Uses test database/Redis (isolated from dev/prod)
- Disables Cribl logging (CRIBL_ENABLED=false)
- Uses test JWT secret

DO NOT run scanners in CI (too slow, requires Docker-in-Docker).
DO keep test execution under 5 minutes if possible.
DO fail CI on coverage regression below 70%.</action>
