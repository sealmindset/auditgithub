# Phase 20 Plan 01: Schedule Creation UI

## Objective

Allow users to create schedules for repositories that don't have one, with AI recommendation or manual configuration options.

## Execution Context

**Phase dependencies:**
- Phase 19: Repository Schedule Table (provides UI for unscheduled repos)
- v1.0: Existing schedule models and AI recommender service

**Key files to create/modify:**
- `src/api/routers/schedules.py` - Add POST endpoint and recommend endpoint
- `src/web-ui/components/ScheduleCreateDialog.tsx` - New dialog component
- `src/web-ui/app/scheduler/page.tsx` - Wire up dialog

## Tasks

### Task 1: Add API Endpoints

Add two new endpoints to schedules.py:
- POST `/schedules` - Create a new schedule for a repository
- GET `/schedules/{repo_id}/recommend` - Get AI recommendation for a repo

### Task 2: Create ScheduleCreateDialog Component

Create dialog with:
- AI/Manual mode toggle
- AI recommendation display with confidence and reasoning
- Frequency selector (daily, weekly, bi-weekly, monthly)
- Day of week selector (for weekly/bi-weekly)
- Time window selector
- Error handling

### Task 3: Wire Up to Scheduler Page

- Add dialog state management
- Update handleCreateSchedule to open dialog
- Refresh data after schedule creation

## Success Criteria

- [x] POST /schedules endpoint creates schedules
- [x] GET /schedules/{repo_id}/recommend returns AI recommendations
- [x] Dialog opens when "+ Schedule" clicked
- [x] AI recommendation loads and displays
- [x] Manual mode allows custom configuration
- [x] Schedule creation refreshes table data
