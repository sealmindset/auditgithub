**From RESEARCH.md:**
- Standard Stack: PostgreSQL schemas with SET search_path, SQLAlchemy 2.0, psycopg2.sql.Identifier for SQL injection safety
- Architecture Pattern: POST /tenants → background task → CREATE SCHEMA → Base.metadata.create_all() → Alembic migrations
- Common Pitfall: Schema injection via user input - MUST use parameterized queries and Identifier quoting
- Don't Hand-Roll: Schema creation logic (use SQLAlchemy), migration orchestration from scratch (extend Alembic)

  <name>Task 1: Create schema provisioning functions</name>
  <files>src/api/utils/tenant_provisioning.py, src/api/routers/tenants.py</files>
  <action>
Create `src/api/utils/tenant_provisioning.py` with `provision_tenant_schema(tenant_slug: str)` function:

1. Schema name construction: `schema_name = f"tenant_{tenant_slug}"`
2. CREATE SCHEMA using psycopg2.sql.Identifier (NEVER f-strings - SQL injection risk):
   ```python
   from psycopg2 import sql
   query = sql.SQL("CREATE SCHEMA IF NOT EXISTS {}").format(sql.Identifier(schema_name))
   conn.connection.cursor().execute(query)
   ```
3. Set search_path and create tables: `conn.execute(text("SET search_path = :schema"), {"schema": schema_name})` then `Base.metadata.create_all(bind=conn)`
4. Update Tenant record: set is_provisioned=True, migration_status="current", last_migration_at=now()
5. Include try/except with error logging and Tenant.migration_status="error" on failure

Update `src/api/routers/tenants.py` POST /tenants endpoint:
1. Add validation: slug must match `^[a-z0-9-]+$` (lowercase, alphanumeric, hyphens only)
2. Check uniqueness: query Tenant by slug, return 409 if exists
3. Create Tenant record with is_provisioned=False, migration_status="pending"
4. Use BackgroundTasks to call provision_tenant_schema(tenant.slug) asynchronously
5. Return 201 with {"message": "Tenant created, provisioning in progress", "slug": tenant.slug}
6. Require admin:manage permission (Phase 3 RBAC integration)

DO NOT use f-strings for schema names in SQL - use parameterized queries or psycopg2.sql.Identifier. This prevents schema injection attacks where attacker sends slug="foo; DROP SCHEMA tenant_bar CASCADE; --"
